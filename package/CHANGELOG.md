# Changelog

## 1.0.0
- First release. / Primeira versão.
- Anything goes through portals, whatever the world settings. / Qualquer item passa pelos portais, sejam quais forem as configurações do mundo.
- No-portal marks hidden on items and tooltips. / Marcas de "não passa no portal" escondidas nos itens e tooltips.
- Shorter loading screen for far portals. / Tela de carregamento mais curta em portais distantes.
- Portals light up only when you come a bit closer. / Os portais só acendem quando você chega um pouco mais perto.
